# Linkly 🔗

A simple and responsive URL shortener built with **Next.js, MongoDB, and Tailwind CSS**.

## Features

* Create short URLs
* Custom short URLs
* Responsive design
* MongoDB database integration
* Simple and clean interface

## Tech Stack

* Next.js
* React
* Tailwind CSS
* MongoDB
* JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Sidhant575/linkly.git
cd linkly
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and add your environment variables.

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
